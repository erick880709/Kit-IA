# HU-E8-03: Actualizar usuario

## Como
Administrador

## Quiero
actualizar datos, rol o estado de un usuario

## Para
mantener los accesos al día (RF-014).

## Criterios de Aceptación
- [ ] CA1: Edición de rol y estado (activo/inactivo).
- [ ] CA2: Cambio de rol con revalidación de permisos inmediata.
- [ ] CA3: Toda actualización queda en auditoría.
- [ ] CA4: Un administrador no puede desactivarse a sí mismo (sin otro admin activo).

## Dependencias
HU-E8-01
